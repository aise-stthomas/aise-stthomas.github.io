# AI Systems Engineering — course site

Public homepage for the AI Systems Engineering course at the University of St. Thomas,
served by GitHub Pages from `docs/`: the general course description, the design
framework and rubric, the reference design, and the project overview.

Semester-specific material (schedule, slides, labs, homework) lives in a separate
repository per term under this organization. Lecture sources, the book, and instructor
material are maintained privately.
